🌐 Google Search Grounding — System Architecture

Complete 6-Stage Technical Architecture with Pydantic v2 Validation, Pass 2 Fallback Loop, & Emerald Export

← Back to Web App
📁 Stage 1: Ingestion & Missing Attribute Detection Stage 1
  • File Upload: Parses supplier catalog CSV / XLSX files up to 32 MB.
  • Schema Parser: Auto-detects Identity Columns (Product Name, Brand, MPN) vs. Target Attribute Columns.
  • Missing Cell Map: Identifies missing attribute cells per row and calculates baseline catalog coverage %.
↓
⚡ Stage 2: Parallel ThreadPool Worker Dispatcher Stage 2
  • Parallel Workers: Dispatches rows asynchronously across 5–10 parallel worker threads.
  • Dynamic Prompt Engine: Combines full un-truncated Product String with required target attributes.
↓
🌐 Stage 3: Vertex AI & Google Search Grounding Engine Stage 3
  • Autonomous Multi-Query Search: Gemini formulates live Google Search queries for product specs.
  • Multi-Source Scraper: Scrapes live web pages across OEM manufacturer sites, B2B distributors, and PDF spec sheets:
Source A: OEM / Manufacturer Official Site Extracts core specs: Material, PSI Rating, Temp Limits
Source B: Major B2B Retailer Catalogs Extracts Assembled Dimensions: Height, Width, Depth
Source C: PDF Technical Manuals Extracts electrical specs: Voltage, Wattage, Warranty
↓
🛡️ Stage 4: Pydantic v2 Schema Validation & Unit Normalization Stage 4
  • Unit Symbol Normalization: @field_validator('unit') converts unit synonyms (e.g. "inches" → "in", "lbs" → "lb", "volts" → "V").
  • Data Quality Cleaning: @field_validator('value') cleans string noise ("N/A", "none" → null).
  • Confidence Bounds Check: Enforces confidence bounds 0 ≤ confidence ≤ 100.
↓
🔁 Stage 5: Algorithmic Pass 2 Null-Recovery Fallback Loop Stage 5
  • Algorithmic Null Detection: Python inspects Pass 1 output dictionary for remaining null attributes.
  • Pass 2 Targeted Search: If nulls exist, constructs a hyper-focused search query specifically targeting remaining missing attributes.
  • Result Merging: Merges Pass 2 grounded recoveries into Pass 1 output map for maximum catalog coverage.
↓
📊 Stage 6: Multi-Sheet Emerald Green Excel Export Stage 6
  • Emerald Green Fill: Applies soft emerald green background fill (#D1FAE5) to all newly enriched cells in the Enriched catalog tab.
  • Evidence Trace Sheet: Generates Evidence tab with exact Source Name, Direct Web URL, Confidence Score, and Quote.
  • Review Queue Sheet: Generates Review tab for low-confidence fills (<75).
